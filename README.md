# Coolify.Website
Coolify es una portavasos enfriadora con un termo especial que busca mantener tus bebidas frescas. Está diseñada para cualquier persona que quiera disfrutar de una bebida refrescante y fria, especialmente durante el calor de Monterrey. Con nuestra idea innovadora y práctica, queremos hacer que la frescura te acompañe a donde vayas.
